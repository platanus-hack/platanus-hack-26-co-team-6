# Runbooks

Qué hacer cuando algo se cae. **Uno por página**, con esta forma:

```
síntoma → diagnóstico (comandos exactos) → mitigación → causa raíz → prevención
```

Los escribe la [tarea 5.5](../tareas/sebas.md#55--alertas-y-runbooks). Pendientes:

- [ ] `ai-core caído`
- [ ] `Mapbox agotado`
- [ ] `Supabase caído`
- [ ] `canal muerto` (Telegram/WhatsApp no entregan)
- [ ] `outbox atascado`
- [ ] `restaurar backup`
- [ ] `rotar secreto filtrado`
- [ ] `sede reporta que no le llegan solicitudes`

> **Un runbook no probado es ficción.** Al menos dos se escriben tumbando el
> servicio a propósito y anotando lo que realmente se hizo, no lo que debería
> funcionar en teoría.
